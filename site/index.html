Questions fréquentes

Avant de commencer

Faut-il une connexion internet ?

Non. NEXORA fonctionne sur votre PC sans connexion. Internet sert seulement à envoyer les messages WhatsApp à vos clients.

Sur quel appareil fonctionne NEXORA ?

Sur un PC sous Windows 10 ou 11. Il n'y a pas de version pour téléphone pour l'instant.

Windows affiche « Windows a protégé votre ordinateur ». C'est normal ?

Oui, ce message apparaît pour les logiciels récents. Cliquez sur « Informations complémentaires », puis sur « Exécuter quand même ». Nous pouvons aussi faire l'installation avec vous à distance.

Le navigateur bloque le téléchargement.

Edge ou Chrome peuvent afficher un avertissement pour un logiciel récent. Cliquez sur les trois points (…) à côté du fichier, puis sur « Conserver ». Si vous préférez, nous vous envoyons le fichier sur WhatsApp.

Où sont gardées mes données ?

Sur votre PC, pas sur internet. NEXORA fait une sauvegarde automatique chaque jour et garde les 30 dernières. Vous pouvez aussi les copier sur une clé USB.

Que se passe-t-il après les 7 jours d'essai ?

Vos données restent sur votre PC. Pour continuer à utiliser NEXORA, activez une licence : mensuelle, annuelle ou permanente.

J'ai plusieurs PC dans mon atelier.

Une licence s'active sur un PC. Pour plusieurs postes, écrivez-nous sur WhatsApp pour un prix adapté.

Quelle imprimante faut-il ?

Une imprimante normale pour les factures A4, ou une imprimante thermique de tickets 58 mm ou 80 mm.

Mon pays n'est pas dans la liste.

Choisissez « Autre » dans les paramètres, puis saisissez votre devise et votre indicatif téléphonique.
