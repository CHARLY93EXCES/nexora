# NEXORA

**Logiciel de gestion pour ateliers de réparation de téléphones** — passeport de chaque appareil, diagnostic guidé de 45 pannes, devis, suivi des réparations, reçus avec votre logo et messages WhatsApp aux clients. PC Windows 10 / 11, fonctionne sans internet.

**Software for phone repair shops** — device files, guided diagnosis, quotes, repair tracking, receipts with your logo and WhatsApp messages. Windows 10 / 11, works offline.
